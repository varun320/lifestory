# Design Explorations — Home, three directions

**For Alex to react to.** Each file shows the same content — hero, differentiator section, pull-quote, recognition section, fee-hook section — so the only variable is visual direction. Copy is v0.3 (the sharpened version).

**A note on the copy:** the earlier "What does this money need to do for the life it belongs to?" wording is out. All three now use **"What is this money for?"** — tighter, in the same question direction Alex liked. Two alternates if this still isn't right: "What do you want this money to do?" or "What is this money supposed to do?"

**How the sections work — intent-driven treatment:**
- **Hero** — land three signals fast (name, role, place) and open the story loop.
- **"Why this firm exists"** — the differentiator. Given the most visual weight of any body section, because its job is to distinguish him from the default adviser in one beat.
- **Pull-quote** — one attitudinal statement designed to make the reader stop scrolling.
- **"Who this is for"** — the recognition beat. Given a distinct treatment (color shift, italic lead-in) so the right reader feels *this is me* in the first sentence.
- **"What it costs"** — the fee hook. A two-word answer (*Potentially nothing.*) treated at display scale, followed by a short explanation. This is where each direction reveals how it handles a punch — three very different answers below.

**Open each `.html` file by double-clicking it.** Try each at desktop width and resize to phone width.

## 1 · The Journal — `01-the-journal.html`

Editorial, publication-like. Serif throughout (EB Garamond), narrow measure, dateline strip under the masthead, ink-on-cream palette. Deep muted oxblood accent (softened from the earlier bright red — reads editorial, not magazine-cover).

**Feels like:** a piece you would sit down and read.
**Design serves intent via:** long-form serif rewards the differentiator section; centered italic pull-quote with hairline rules commands the scroll pause; recognition section uses an italic serif lead-in so it reads as personal address, not marketing. **Fee hook** answers on a warm-cream surface change — italic serif *"Potentially nothing."* set large in the oxblood accent, so the answer reads like an editorial reply to an unspoken question.

---

## 2 · The Firm — `02-the-firm.html`

Warm-professional. Serif display (Cormorant) paired with sans body (Source Sans 3). Deep navy hero, ivory-and-cream main surfaces, restrained brass accent, classical credentials strip.

**Feels like:** a firm you would trust with something serious.
**Design serves intent via:** dark hero forces attention on the H1; two-column body in the differentiator section keeps the pace moving; recognition section uses a warm cream surface change to visually separate it as "a different kind of moment." **Fee hook** goes big — *"Potentially nothing."* set at near-poster scale in the serif display, centered on ivory, framed by rule marks. Reads as premium confidence, not a bullet point.

---

## 3 · Quiet Modern — `03-quiet-modern.html`

Sans throughout (Inter), near-monochrome, deep green accent. Cleaned up from the earlier version — mono type and tech-startup section numbering removed, contrast fixed for AA accessibility on a ~60 audience.

**Feels like:** something current, careful, restrained.
**Design serves intent via:** giant question H1 with room to breathe; two-column labeled section for the differentiator; callout-style pull-quote (accent-soft background) as an intentional stop-scroll; recognition section on a warmer surface so it feels like the tone shifts. **Fee hook** breaks the previous grid rhythm — asymmetric split with the answer set against a coloured left rule, explanation on the right at reading size. The rhythm change itself signals "this is a different kind of moment."

## What is *not* being decided here

## How to give feedback

Point at the file name and say what you like or dislike. Specific is better than general. Examples:
- "The Journal, but the pull-quote is doing too much."
- "Quiet Modern, but warm it up — too much white."
- "None of these — go warmer / colder / more traditional."
