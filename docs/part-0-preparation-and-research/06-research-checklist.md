# 06 · Research Checklist — before writing copy

Do these first. Copy written on shaky facts is worse than no copy.

## Verify

- [ ] Read all of Part 0 end to end. Once. Properly.
- [ ] Visit `lifestorywp.com`. Confirm current-site findings (see `02-current-site-audit.md`) still match today.
- [ ] Open every reference site in `05-reference-sites.md` in a normal browser. Note structure, pacing, how they handle claims.
- [ ] Search Alex's personal name and firm name. Record what actually appears on page one — LinkedIn, regulator DB, data brokers, competing "Life Story Financial", etc.
- [ ] Confirm exact spelling **Tzur Magen** (it has been transcribed wrongly elsewhere).
- [ ] Confirm the fee wording verbatim from the live site (see `part-1/02-preserved-substance.md`) — including the "managements" typo.

## Read as a compliance reviewer, not a marketer

Before opening the copy deck, re-read `03-compliance-rules.md`. If any section idea would need a testimonial, a return figure, a superlative, or a worked fee example to work — that section needs to be restructured, not written.

## Confirm the gaps

Cross-check `../open-gaps.md`. Do not begin writing anything that depends on a gap without either an answer or an explicit `[NEEDS CONFIRMATION: …]` marker plan.

## The audience test

For every section idea, ask: **"Would a careful, wealthy, 60-year-old stranger who was just referred to Alex find this reassuring, or does it feel like pressure?"** Pressure reads as desperation. Cut.

## Route of questions

All questions → Arham → client (and counsel where needed). Never contact client directly.
